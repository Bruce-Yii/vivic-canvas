## 限制

这些目录来自不同时间和部署组件，不能视为同一版本的完整源代码。服务器上的前端在 10 月 25 日之后继续更新；尚未找到与当前线上前端完全对应的完整源码或原始 Git 历史。部署配置、生产密钥、数据库、用户内容及备份没有纳入仓库。不要直接将这些文件覆盖到生产服务器。

`source-snapshot-20261025/package.json` 列出的部分脚本未包含在部署包中；能否从该快照构建尚未验证。请先找到原始开发仓库并对照线上版本，再确定开发和部署流程。
